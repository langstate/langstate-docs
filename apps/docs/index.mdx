LangState is an early Python framework for representing uncertain, inferred application state alongside a resolved business state. It provides state data structures, schema extraction, mutation and projection contracts, evaluation helpers, and storage interfaces for systems that collect structured data through natural interaction.

<Warning>
  LangState is a **source-only alpha**. There is no LangState release to install from PyPI, and the `langstate` name on PyPI belongs to an unrelated project. Start with [Installation](/installation) and a pinned source checkout.
</Warning>

## Documentation baseline

These pages describe repository version **{{version}}**, pinned to commit [`{{commit}}`](https://github.com/langstate/langstate/commit/df40bc49bc8e3a51b2bb695b30ff93ef81b2cc4b). The documented verification command passes **628 tests** at that commit.

| Area | What exists at the pinned commit |
| --- | --- |
| State | Canonical and interpretive state implementations backed by a directed acyclic hypergraph |
| Schema input | An `OpenAPIReader` and `StateFactory` used by the Registration integration test |
| Mutation | Abstract mutator contracts plus an `LLMMutator` that depends on a caller-supplied LLM client |
| Projection | Abstract canonical-state and UI projector contracts |
| Evaluation | Field-by-field mutator evaluation through `LLMEvaluator` |
| Persistence | Independent in-memory state repository and bounded snapshot store |
| Orchestration | An abstract `LangState` contract; adopters must provide a subclass and extension implementations |

LangState is a Python library for managing state in language-driven applications. It models state as a schema-backed graph and keeps two synchronized views:

- **Interpretive state** for inferences, candidate values, and confidence
- **Canonical state** for resolved, execution-ready values

The core `LangState` orchestrator wires together spec extractors, mutators, projectors, and repositories so applications can move from user input to validated state and UI output.

## What LangState gives you

<CardGroup cols={2}>
  <Card title="Schema-backed state" icon="sitemap">
    State is stored as a graph of field paths, not a single flat blob. Nested objects and array paths are first-class.
  </Card>
  <Card title="Confidence-aware values" icon="gauge-high">
    Each field can keep multiple candidate values with confidence scores and the latest inference that produced them.
  </Card>
  <Card title="Pluggable orchestration" icon="puzzle-piece">
    Spec extractors, mutators, projectors, and repositories are independent contracts that can be swapped without rewriting the whole flow.
  </Card>
  <Card title="Evaluation support" icon="flask">
    The evaluator compares expected and actual post-state outcomes field by field so mutators can be tested systematically.
  </Card>
</CardGroup>

## State shape

At the orchestrator layer, LangState persists a single current state object. The default payload shape is:

```python
{
    "field_key": {
        "inference": [{"content": "...", "mutator_id": "..."}],
        "values": [{"value": "...", "confidence": 0.95}]
    }
}
```

This shape is represented by `StateSchema` and is designed to preserve both interpretation history and candidate values while the application is still converging on a final answer.

## Core building blocks

| Component | Responsibility |
| --- | --- |
| `LangState` | Coordinates schema loading, state persistence, mutation, and projector notification |
| `BaseSpecExtractor` | Loads schema definitions into LangState-readable structures |
| `BaseMutator` | Updates state from structured user input |
| `BaseProjector` | Observes state changes and produces downstream projections |
| `BaseStateRepository` | Persists the current state object |
| `LLMEvaluator` | Compares expected and actual post-state changes for mutator testing |

This page documents the current development workflow from the `packages/langstate` repository content.

## Working directory

Most package development commands are run from:

```bash
cd packages/langstate
```

## Install dependencies

```bash
poetry install --with dev
```

Optional:

```bash
poetry shell
```

That makes the project virtual environment the default for `python`, `pytest`, and related commands.

## Run tests

Full test suite:

```bash
poetry run pytest
```

Unit tests only:

```bash
poetry run pytest tests/unit
```

Integration tests only:

```bash
poetry run pytest tests/integration
```

Single focused test:

```bash
poetry run pytest tests/integration/core/test_state_from_openapi.py::TestSchemaParsing::test_schema_loads_successfully
```

## Focused debugging

When you need stdout, breakpoints, or a smaller target, run a focused test with `-s`:

```bash
poetry run pytest tests/unit/state/test_base_state.py -k snapshot -s
```

Debugging notes:

- Use `breakpoint()` inside the package code.
- Run pytest with `-s` so `pdb` can take control.
- Narrow the selection with `-k` or a fully qualified test path before debugging the full suite.

## Save integration test artifacts

To persist integration test outputs:

```bash
TEST_OUTPUT=true poetry run pytest tests/integration/core/test_state_from_openapi.py -s
```

Generated artifacts are written under:

```text
tests/integration/core/test_outputs
```

This quickstart is based on the current `packages/langstate` source tree.

## Prerequisites

- Python 3.10+
- Poetry
- A local checkout of the `agentize/langstate` repository

## 1. Install the package for development

```bash
git clone https://github.com/agentize/langstate.git
cd langstate/packages/langstate
poetry install --with dev
```

If you want `python`, `pytest`, and related commands to run inside the project environment automatically, open a Poetry shell:

```bash
poetry shell
```

## 2. Create a state object

The most concrete way to get started today is to work directly with the state model.

```python
from langstate.core import Inference, State, ValueConfidence

state = State()

state.add_inference(
    "registrant.name",
    Inference(content="User said their name is John Doe", mutator_id="user_input"),
)
state.add_value(
    "registrant.name",
    ValueConfidence(value="John Doe", confidence=0.95),
)
state.add_value(
    "registrant.email",
    ValueConfidence(value="john.doe@example.com", confidence=0.92),
)
```

Field paths can be nested object paths like `registrant.name` or array paths like `guests.0.email`.

## 3. Work with structured interaction input

LangState models user interaction with structured input objects rather than plain strings:

```python
from langstate.core import AgentInput

text_input = AgentInput.from_text("Book the registration for John Doe")
selection_input = AgentInput.from_selection(["vip"], field_id="registration.tier")
confirmation_input = AgentInput.from_confirmation("registrant.email", True)
```

These inputs are designed to feed a concrete `LangState` implementation that defines `initialize()`, `invoke()`, and `reset()`.

## 4. Understand the orchestration boundary

The exported `LangState` class is an abstract base class. Applications are expected to provide concrete orchestration by composing:

- a spec extractor
- a mutator
- one or more projectors
- a state repository

The package documentation in [Architecture](/architecture/overview) covers those contracts in more detail.

## 5. Run the existing test suite

```bash
poetry run pytest
```

Useful subsets:

```bash
poetry run pytest tests/unit
poetry run pytest tests/integration
```

<Tip>
  If you want an example grounded in the current repository, use the integration tests around OpenAPI-driven state generation as the reference implementation for how the pieces fit together today.
</Tip>
